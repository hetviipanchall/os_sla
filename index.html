Algorithm Explanation

1. Barber: If no customers are available, the barber sleeps.

2. Customer Arrival: A customer wakes the barber if the barber is sleeping.

3. Waiting Room: If the barber is busy, the customer waits in an available chair.

4. Full Waiting Room: If every waiting chair is occupied, the arriving customer leaves.

5. Synchronization: In the classic operating-system solution, semaphores coordinate access to the waiting chairs and barber. This page illustrates the algorithm visually; it does not create real OS threads or semaphores.
